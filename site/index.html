Funcionalidades

Tudo o que você usa no Mobills ou no Organizze. No seu servidor.

Do orçamento da casa ao caixa da empresa, sem assinatura e sem entregar seus extratos para ninguém.

Contas e cartões

Contas, cartões com faturas e parcelamento, transferências e contas a pagar e a receber com calendário de vencimentos.

Análise

Dashboard, projeção de fluxo de caixa com alerta de saldo negativo, orçamentos, metas e relatórios em Excel, PDF e CSV.

Automação

Recorrências, importação de extratos OFX/CSV dos bancos brasileiros com deduplicação e categorização automática.

Multi-organização

Pessoal, família e empresa na mesma instância, com dados isolados, papéis (owner, admin, member, viewer) e convites.

Segurança

2FA, criptografia de campo AES-256-GCM, audit log e ferramentas de LGPD para exportar e excluir a conta.

Em qualquer tela

PWA instalável, modo escuro, modo privacidade que oculta valores e interface em pt-BR, inglês e espanhol.

Como funciona

Três comandos. Está rodando.

Zero conta na nuvem, zero cartão de crédito, zero dado seu pra ninguém.

01

Clone

Pegue o código do repositório oficial. AGPL-3.0, sem chave de licença.

bash
$ git clone https://github.com/diego-luz/finance.sh
$ cd finance.sh
02

Deploy

Gere o .env com segredos próprios da sua instalação e suba o stack num comando.

bash
$ ./scripts/gen-env.sh
$ docker compose up -d --build

# 2 containers: app + Postgres

03

Acesse

Abra o navegador, informe o código de instalação do log e crie o primeiro admin pelo assistente.

bash
$ docker compose logs app
$ open http://localhost:8090

# Assistente inicial: admin, organização, idioma

Roda em qualquer host com Docker 24+: desktop, VPS, homelab, NAS ou Raspberry Pi. Sem dependência externa e sem telemetria.

FAQ

Perguntas frequentes

É grátis mesmo?
Sim. O finance.sh é software livre sob a licença AGPL-3.0: sem assinatura, sem chave de licença e sem limite de usuários. Você só paga, se quiser, pelo servidor onde ele roda.
Preciso de um servidor? Do que preciso para rodar?
De qualquer máquina com Docker 24+ e Compose v2: seu próprio computador, um NAS, um Raspberry Pi, um homelab ou uma VPS. São só dois containers (app + Postgres).
Meus dados vão para algum lugar?
Não. Tudo fica no banco Postgres da sua instalação. O finance.sh não tem telemetria e não depende de serviços externos para funcionar.
Consigo importar o extrato do meu banco?
Sim, por arquivos OFX ou CSV exportados do internet banking. A importação evita lançamentos duplicados e sugere a categoria com base em regras e no seu histórico.
Dá para separar finanças pessoais e da empresa?
Sim. Cada instalação suporta várias organizações (ex.: Casa, Família e Microempresa), com dados totalmente isolados e um seletor para alternar entre elas.
E se eu quiser sair?
Exporte tudo em OFX, CSV, JSON, PDF ou Excel quando quiser. O export em JSON também serve para migrar os dados para outra instalação.
Esqueci a senha e não configurei e-mail. E agora?
Dá para recuperar sem SMTP: pelo comando -reset-password no servidor, por um link impresso no log ou por um super-admin. Veja o guia de instalação.
Como posso contribuir?
Issues e pull requests são bem-vindos. Comece pelo guia de contribuição e pelo roadmap. Deixar uma estrela no GitHub também ajuda o projeto a ser encontrado.
